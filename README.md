# NFS Heat VR

![NFS Heat VR](nfs_heat_vr.png)

For a long time, I didn't know if there would be a mod for the NFS series, so I decided to create my own. I chose HEAT.

I'm still working on and finalizing the proper display of the game in the headset.

I'm initially testing everything on the `Pimax 8KX`, as I want to achieve full immersion with a wide field of view, but I also want to test it on other headsets in the future. Stay tuned, I'll be uploading a test build soon.

I've attached a video so everyone can see my tests.

The mod is free, but I'd appreciate your support if you buy my main game, CYBRID.
