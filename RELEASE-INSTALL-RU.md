# NFS Heat VR — установка

Это готовая экспериментальная VR-версия для PC-версии Need for Speed Heat (Steam / EA App).

1. Закройте игру.
2. Запустите используемый OpenXR-рантайм: Pimax Play, SteamVR, Meta Quest Link или другой совместимый.
3. Откройте папку игры — в ней находится `NeedForSpeedHeat.exe`.
4. Распакуйте **всё содержимое ZIP-архива прямо в эту папку**. Не оставляйте файлы во вложенной папке архива.
5. Запустите `NFSHeatVRControl.exe`, при необходимости укажите желаемое разрешение игры и нажмите **Launch NFS Heat VR**.

Во время игры:

- `Home` — открыть настройки;
- `F8` — включить / выключить поворот и 6DoF головы;
- `F9` — центрировать положение и направление головы;
- `Ctrl+F3` — включить / выключить depth stereo.

Перед первой правкой разрешения лаунчер создаёт резервную копию игрового профиля: `PROFILEOPTIONS_profile.NFSHeatVR.backup` в `Документы\Need for Speed Heat\settings`.

## Важно

- Мод рассчитан на D3D11 и протестирован на версии игры `1.0.60.7040` / Steam build `10351341`.
- Используйте его только в одиночной игре.
- Стерео по глубине — реконструкция одного кадра, а не два полноценных рендера камеры. На сильных значениях у краёв объектов возможны артефакты.
- Для удаления мода достаточно удалить четыре файла: `NFSHeatVRControl.exe`, `NFSHeatVRLauncher.exe`, `NFSHeatVRRuntime.dll`, `NFSHeatVR.ini`. При необходимости восстановите созданную резервную копию игрового профиля.
